# 这个项目是什么（通俗版）

> 一句话：**把一台安卓手机，改造成一台能跑普通 Linux 的小电脑。**

---

## 一、用大白话说

手机出厂时装的是安卓。安卓底下其实压着两层东西：一层是「Linux 内核」（负责跟硬件打交道），
另一层是安卓自己的界面和服务。

我们做的事，是**把上面那层安卓整个拿掉，换成普通的 Linux 系统**——就是跑在服务器、
树莓派上的那种。装好后手机不再是手机，而是一台：

- 能连 WiFi、能用 SSH 远程登录的小电脑
- 能跑各种服务（网页、脚本、定时任务）的服务器
- 屏幕只显示文字，没有触摸界面（本来也没打算用它当手机）

这跟「刷机」「装个 App」完全不是一回事：**整个系统底层都换掉了**。

---

## 二、现在它能做什么

| 能做的事 | 说明 |
|---|---|
| 开机进 Linux | 完全自动，不用手动操作 |
| 连 WiFi 上网 | 实测下载 60–70 Mbps |
| SSH 远程登录 | 像操作服务器一样操作它 |
| 连蓝牙耳机 / 音箱 | 可以正常放音乐 |
| **刷门禁卡（NFC）** | 贴一下卡，能读出卡号，并让耳机「滴」一声 |
| 发射红外 | 可以当遥控器 |
| 当服务器长期运行 | 有看门狗（死机会自动重启）、自动自检、压缩内存、充电保护 |

## 三、现在还做不到的

- **外放喇叭和麦克风** —— 这是最难的一块，卡在功放（CS35L41）的保护固件上，还在攻关
- **屏幕没有图形界面** —— 只有文字界面
- 相机、指纹、GPS、4G 上网、传感器 —— 都还没做

---

## 四、★ 这是一个 AI 项目

**这个移植项目，主要的开发和调试工作是由 AI 完成的。**

具体来说：

- 机主（人类）负责**动手**：插线、刷机、重启、贴卡、听声音、确认现象
- **AI 助手**负责**绝大部分技术工作**：读内核源码、改驱动、写设备树、编译、分析日志、
  定位 bug、写工具程序、查资料、写文档
- 整个过程的每一次改动、每一个踩过的坑、每一条结论，都记录在 `docs/` 里

换句话说，这不是「有人写好了教程、机主照着做」，而是
**「AI 一边读源码一边做实验，一个 bug 一个 bug 把手机点亮」**。

这件事本身比移植结果更有意思：**一台手机的底层系统移植，AI 已经能承担主力工作**。

## 六、别人可能会问的问题

**Q：这不就是刷机吗？**
A：不是。刷机是换安卓的不同版本，本质还是安卓。我们是把安卓整个换掉，装上电脑用的 Linux。

**Q：难在哪？**
A：手机有一百多个零件，每个都要「驱动」告诉系统怎么用它。官方只提供了安卓版的驱动，
我们得一个个重写或者找现成的。最麻烦的是音频、相机这类和芯片内部深度绑定的模块。

**Q：AI 真的能独立做这种事？**
A：能承担主力。它会读内核源码、分析日志、改代码、编译、反复试错、记录结论。
人类提供的是「手」和「眼睛」——刷机、重启、听声音、看现象。两者配合效率很高。

**Q：花了多久？**
A：从点亮屏幕到现在的功能，跨了几天，中间大量时间是跟各种奇怪的硬件问题死磕。
