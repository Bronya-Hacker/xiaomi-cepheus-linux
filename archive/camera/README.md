# 相机移植（已封存，后续再启）

2026-10-20 一轮完整攻关到此为止，**SoC 侧全部打通并真机验证**，
卡在相机模组本身不上电（详见 `docs/camera-port.md` §8–§15）。

## 这里有什么

| 目录 | 内容 |
|---|---|
| `camcc-sm8150/` | 相机时钟 + 6 个 GDSC 的主线驱动（真机验证：96 时钟、0 oops） |
| `camss-sm8150/` | camss 资源表、CCI 驱动补丁、DT 文件、i2cscan 调试模块 |
| `imx586-tables/` | 从 Rockchip 内核移植的 IMX586 驱动（可编译），以及厂商 ROM 的 sensormodule .bin |

## 结论摘要

- ✅ 时钟（96 个）、GDSC（6 个）、采集管线（csiphy/csid/vfe、video0-7）、
  CCI 总线（SM8150 兼容）、传感器驱动（可编译）全部完成；
- ❌ 传感器 `0x1a` 两条 CCI master 都不应答；而 `0x51` 经证实是**主板**芯片，
  所以不能作为"模组有电"的证据；
- 我们的电源树与原厂完全一致（VANA 1.904V / VDIG 2.856V / VIO 1.8V /
  VDIG0 开关 GPIO59 / MCLK1 GPIO14 / 复位 GPIO30），仍不响应；
- **最可能的原因：模组本身没有上电或已损坏**，需要排线图纸或换模组才能继续。

## 重启条件

1. 拿到主摄排线/接口引脚定义；
2. 或确认该机相机在官方系统下工作正常（排除硬件故障）；
3. 有第二台机器时，可在真机上继续调试而不用担心影响服务。
